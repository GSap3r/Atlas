Organizador de Excursões

Sistema local para organizar excursões, controlar passageiros, assentos, pagamentos e finanças.

Abrir o Sistema →
⚠️ Os dados ficam salvos no navegador do seu computador. Exporte backup regularmente via menu Backup.

Como usar

  • Abra o arquivo Abrir Organizador.html no navegador
  • Um exemplo de excursão (Gramado Julho) é carregado automaticamente
  • Use o menu lateral para navegar
  • Clique em uma excursão para gerenciá-la
  • Use as abas dentro de cada excursão para gerenciar passageiros, assentos, pagamentos e contas

Estrutura de arquivos

  • Abrir Organizador.html — Arquivo principal (abrir este)
  • assets/css/style.css — Estilos visuais
  • assets/js/app.js — Lógica principal
  • assets/js/db.js — Banco de dados local (IndexedDB)
  • assets/js/backup.js — Exportar/importar backup
  • assets/js/pdf.js — Geração de relatórios/PDF
  • assets/js/utils.js — Funções auxiliares
  • exemplos/excursao-exemplo.json — Exemplo de backup

Funcionalidades

  • Dashboard com resumo financeiro geral
  • Múltiplas excursões com cores personalizadas
  • Cadastro completo de passageiros
  • Mapa visual de assentos do ônibus
  • Histórico de pagamentos por passageiro
  • Contas a pagar por excursão
  • Resumo financeiro com ponto de equilíbrio
  • Lista de embarque para imprimir
  • Relatórios em PDF e CSV
  • Backup completo em JSON

Backup

Vá em Backup no menu lateral e clique em Baixar Backup Agora. Guarde o arquivo .json em local seguro (nuvem, pendrive, etc).

Para restaurar, use o botão Importar Backup e selecione o arquivo .json.
